A deadpan one-star review of gravity, filed in earnest against an everyday
essential that cannot be fixed: no off switch, no pause button, and no
refund policy. Everything owned has hit the floor at least once.

Run `python3 main.py` — it writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt`) and verifies it byte-for-byte.
